## Getting Started

### Prerequisites
Make sure you have Python 3.14.7 installed on your local environment.

### Installation & Environment Setup
1. Clone this repository to your machine:
   ```bash
   [git clone https://github.com](https://github.com/shyamalkar/Python_Universe_org.git)
   ```
2. Navigate into the project directory:
   ```bash
   cd Python_Universe_org
   ```
3. Set up a virtual environment to manage dependencies neatly:
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows use: venv\Scripts\activate
   ```
